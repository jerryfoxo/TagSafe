# TagSafe

TagSafe is a configurable content-warning tag helper for Bluesky.

It adds quick tag controls directly to the Bluesky post composer, making it easier to add consistent content warnings without manually typing the same tags every time.

TagSafe can also optionally synchronize the selected warning tags with image ALT text while preserving any existing ALT description.

> TagSafe is not affiliated with, endorsed by, or officially connected to Bluesky Social PBC.

---

## Features

- Quick content-warning tag buttons
- Custom tag categories
- Tag presets
- Save your preferred tags as the default
- Automatically inserts a managed `CW:` line into posts
- Post tags can be turned on or off
- Optional image ALT tag synchronization
- Existing ALT descriptions are preserved
- Import and export settings using normal `.txt` files
- Custom presets and conflicts
- Light and dark theme support
- Settings are stored locally in your browser
- No TagSafe account required
- No analytics
- No tracking
- No external TagSafe server

---

## How it works

TagSafe appears directly inside the Bluesky post composer.
