# Privacy Policy

TagSafe is designed to operate locally in your browser.

## Data collection

TagSafe does not collect, sell, share, or transmit personal data to the developer.

TagSafe does not operate an external server.

## Bluesky content

To provide its functionality, TagSafe interacts with the Bluesky post composer and, when enabled, image ALT-text controls.

This may include access to:

- post text currently being edited
- selected TagSafe content-warning tags
- image ALT text
- Bluesky composer interface elements

This information is used locally to provide TagSafe's features.

TagSafe does not send this content to the developer.

## Local storage

TagSafe uses the browser extension storage API to save settings such as:

- configured tags
- tag categories
- presets
- conflicts
- default tags
- Post tags preference
- ALT tags preference

These settings remain in browser storage unless removed by the user or browser.

## Network requests

TagSafe does not intentionally send TagSafe data to an external TagSafe service.

The extension operates on:

https://bsky.app/

Bluesky itself may process data according to Bluesky's own privacy policy when you use the Bluesky website.

## Analytics and tracking

TagSafe does not include advertising, analytics, or tracking software.

## Changes

This privacy policy may be updated if TagSafe's functionality changes.

Any significant privacy-related changes will be documented in the project repository.

## Contact

Privacy questions or concerns can be reported through the TagSafe GitHub repository.
