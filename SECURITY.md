# Security Policy

## Reporting a security issue

If you discover a security vulnerability in TagSafe, please report it responsibly.

Please avoid publicly disclosing serious security vulnerabilities before they can be investigated and fixed.

If GitHub private vulnerability reporting is enabled for this repository, please use that feature.

Otherwise, open an issue that does not include sensitive exploit details and request a private way to provide additional information.

## Examples of security issues

Security issues may include:

- imported configuration content causing unintended code execution
- TagSafe modifying post text outside its managed CW line
- unexpected access to data outside the Bluesky composer
- unsafe use of browser extension permissions
- unintended transmission of user data
- vulnerabilities introduced by future dependencies

## Supported versions

The latest released version of TagSafe is the version actively supported.

Older versions may not receive security fixes.

## Scope

Normal Bluesky website bugs or Bluesky account security issues should be reported to Bluesky rather than TagSafe.
