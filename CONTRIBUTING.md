# Contributing to TagSafe

Thanks for your interest in TagSafe.

Bug reports, suggestions, documentation improvements, and code contributions are welcome.

## Reporting bugs

Please include as much relevant information as possible:

- TagSafe version
- browser name
- browser version
- operating system
- steps to reproduce the problem
- expected behavior
- actual behavior
- whether Post tags were enabled
- whether ALT tags were enabled

Screenshots can be helpful.

Please remove private information such as:

- private post text
- email addresses
- account information
- private usernames
- personal messages

before uploading screenshots or logs.

## Feature requests

Feature requests are welcome through GitHub Issues.

Please describe:

- what problem the feature would solve
- how you expect it to work
- whether it changes TagSafe's permissions or privacy behavior

## Pull requests

Before submitting a pull request:

1. Keep changes focused on one problem or feature where practical.
2. Test the change on Bluesky.
3. Avoid adding unnecessary browser permissions.
4. Do not add tracking, analytics, or advertising.
5. Preserve user-written post and ALT content.
6. Keep imported settings files data-only.

Please explain what the pull request changes and how you tested it.

## Code style

TagSafe currently uses plain JavaScript and CSS without a build system.

Try to follow the existing formatting and naming conventions.

## Security issues

Do not publish detailed security vulnerabilities as normal public issues.

See `SECURITY.md` for responsible disclosure information.
