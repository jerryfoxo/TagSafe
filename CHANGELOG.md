# Changelog

All notable changes to TagSafe will be documented in this file.

## [1.0.0] - Unreleased

### Added

- Content-warning tag controls inside the Bluesky composer
- Configurable tag categories
- Tag presets
- Saved default tags
- Post tags toggle
- Optional ALT tag synchronization
- Existing ALT-description preservation
- Plain-text settings import and export
- Tag conflicts
- Light and dark theme support
- Local browser storage for settings
- Optional vore-focused configuration

### Fixed

- Improved TagSafe placement during Bluesky composer loading
- Prevented managed CW updates from replacing normal post content
